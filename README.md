# Job Application Tracker

A Flask-based web application to track job applications efficiently.

## Features

- Add job applications
- Track application status
- Delete applications
- Persistent storage using SQLite
- Simple and clean UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS

## Project Structure

```plaintext
job-application-tracker/
│
├── app.py
├── jobs.db
├── requirements.txt
├── templates/
├── static/
```

## How to Run

1. Clone the repository

```bash
git clone <repo-link>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open in browser

```plaintext
http://127.0.0.1:5000
```
